# Package Configuration

These files are optional reference configuration shipped with pi-coder-tuned.
They are not copied over an existing Pi installation automatically.

- `settings.json`: package settings reference; review before adopting.
- `AGENTS.md`: global coding-agent rules reference.
- `AGENTS.core.md`: compact rules used by the core-rules extension.
- `web-search.json`: web-access configuration reference.

Machine-specific model registrations, API keys, MCP executable paths, sessions,
and local state are intentionally excluded from this package.
